# Dostaffkin

Простое Angular-приложение для оформления и отслеживания доставки.

## Установка

```bash
npm install
```

## Запуск в режиме разработки

```bash
npm start
```

После этого приложение будет доступно по адресу:

```text
http://localhost:4200/dostaffkin
```

## Сборка проекта

```bash
npm run build
```

## Полезные команды

- `npm run start` — запуск dev-сервера
- `npm run build` — сборка проекта
- `npm run builg` — алиас для сборки
